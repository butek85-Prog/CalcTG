# Telegram Mini App «Калькулятор стоимости услуги»

Современное веб-приложение (Telegram Mini App / WebApp) для интерактивного расчёта стоимости услуг с поддержкой тёмной/светлой темы Telegram, безопасных зон (Safe Area), нативных кнопок `MainButton` и `BackButton`, промокодов и автономной работы в любом веб-браузере.

Приложение реализовано **полностью на стороне клиента (SPA)**, без backend и без базы данных.

---

## 🌟 Ключевые возможности

1. **Выбор одной из трёх базовых услуг:**
   - 🚀 **Лендинг / Одностраничный сайт** — базовая стоимость **15 000 ₽** (срок: 3–5 дней).
   - 🛍️ **Интернет-магазин / Каталог** — базовая стоимость **32 000 ₽** (срок: 7–12 дней).
   - 🤖 **Telegram-бот / Mini App** — базовая стоимость **45 000 ₽** (срок: 10–14 дней).

2. **Дополнительные опции с фиксированной ценой:**
   - 💳 Подключение онлайн-оплаты (ЮKassa / CloudPayments) — **+6 000 ₽**
   - 📊 Интеграция с CRM / Таблицами (AmoCRM, Bitrix24, Sheets) — **+8 000 ₽**
   - 🔍 SEO-оптимизация и регистрация в поисковиках — **+4 500 ₽**
   - 🌐 Домен, SSL-сертификат и корпоративная почта — **+3 000 ₽**

3. **Специальные условия с процентной наценкой (рассчитываются от базовой стоимости услуги):**
   - ⚡ Срочная разработка (в 2 раза быстрее) — **+30%** (динамический расчёт в рублях на карточке)
   - ✨ Премиум UI/UX дизайн и анимации — **+20%** (динамический расчёт в рублях на карточке)
   - 🛡️ Приоритетная техподдержка (6 мес.) — **+15%** (динамический расчёт в рублях на карточке)

4. **Промокод `START10`:**
   - Предоставляет скидку **10%** на общую стоимость заказа.
   - Поддерживает регистронезависимый ввод (`START10`, `start10`).
   - Отображает статус валидации, бейдж применённого промокода и сумму экономии в рублях.
   - Возможность в любой момент отменить/удалить промокод нажатием кнопки ✕.

5. **Автоматический мгновенный пересчёт:**
   - Пересчёт итоговой суммы происходит в реальном времени при любом клике, переключении опций или изменении промокода.
   - Детализация по статьям затрат на экране калькулятора.

6. **Экран проверки выбранных параметров (Review Screen):**
   - Полная спецификация заказа в виде квитанции: выбранная услуга, перечень опций, процентные надбавки, промокод, подытог и итоговая цена.
   - Поля для ввода контактов клиента (Имя, Telegram/Телефон, комментарий к проекту).
   - Автоматическое предзаполнение имени и username из профиля Telegram (`initDataUnsafe.user`).
   - Кнопка «← Изменить параметры расчёта» для возврата к редактированию (все введённые данные сохраняются).

7. **Экран успешного подтверждения (Success Screen):**
   - Анимированная индикация подтверждения.
   - Уникальный номер сформированной заявки (например, `#TG-84920`).
   - Итоговая квитанция с полным составом проекта.
   - Кнопка «📋 Скопировать детали заказа» для удобного сохранения текста.
   - Кнопка «🔄 Рассчитать другой проект» для сброса и создания нового расчёта.
   - Отправка данных через `Telegram.WebApp.sendData(...)` при запуске через клавиатуру бота.

8. **Поддержка Telegram WebApp API:**
   - Нативная кнопка **MainButton**:
     - На 1-м экране: «Перейти к проверке • {Итого} ₽»
     - На 2-м экране: «Подтвердить заказ • {Итого} ₽»
     - На 3-м экране: «Новый расчёт»
   - Нативная кнопка **BackButton**: отображается на экране проверки и возвращает пользователя к калькулятору.
   - Тактильный отклик **HapticFeedback**: виброотклик при выборе опций, переключении услуг и подтверждении заказа (`light`, `medium`, `success`, `error`).
   - Полноэкранный режим: вызовы `expand()` и `ready()`.
   - Поддержка тем Telegram (`themeParams`): автоматическая подстройка под цвета оформления Telegram (светлая/тёмная тема).
   - Безопасные зоны (**Safe Area**): поддержка `safe-area-inset-*` и `content-safe-area-inset-*` для корректного отображения на экранах с вырезами (iPhone Notch / Dynamic Island / Android bars).

9. **Работа в обычном браузере:**
   - Автономная работа без окружения Telegram.
   - Автоматическое отображение стилизованной плавающей панели MainButton внизу экрана.
   - Кнопка «Назад» в шапке приложения.
   - Переключатель тем оформления (☀️ / 🌙) в шапке для тестирования тёмной и светлой темы.

## 🤖 Запуск Telegram-бота

В проект добавлен готовый Telegram-бот на `aiogram 3.x`, настроенный с вашим токеном:
`8980754849:AAGw3dSc4dL_kvqIPjdedUTG5xFnyD48yHM`

### Как запустить:

1. В файле [`.env`](file:///d:/CalcTG/.env) укажите URL, где размещено Mini App (например, ссылка с ngrok или GitHub Pages):
   ```env
   BOT_TOKEN=8980754849:AAGw3dSc4dL_kvqIPjdedUTG5xFnyD48yHM
   WEBAPP_URL=https://your-domain.com
   ```
2. Запустите бота командой:
   ```powershell
   python bot.py
   ```
3. Откройте вашего бота в Telegram и отправьте `/start`.
   Бот отправит кнопку запуска Mini App и настроит кнопку меню «Калькулятор».
   При подтверждении заказа в Mini App бот автоматически получит данные заявки и отправит структурированную квитанцию прямо в чат!

## 🚀 Запуск и тестирование локально

### Вариант 1. Через встроенный HTTP-сервер Python

Выполните команду в терминале:

```powershell
python -m http.server 8080
```

Затем откройте в браузере:
👉 **[http://localhost:8080](http://localhost:8080)**

### Вариант 2. Прогон автоматических тестов

```powershell
python test_app.py
python test_server.py
python test_bot.py
```

Все тесты проверяют корректность математических формул, логику скидки 10% по промокоду `START10`, обработку опций, отдачу файлов и конфигурацию бота.
